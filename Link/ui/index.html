보내는 맥에서 ‘보내기 시작’을 누른 뒤 연결하세요. 첫 연결 때는 6자리 번호가 나와요.

준비됐어요.

‘전체 화면’에서는 Windows 키·Alt+Tab 같은 시스템 키도 맥으로 보내요. 전체 화면에서 나가려면 Esc를 길게 누르세요.

연결이 안 되나요?

[파이널 퓨전 받기 · 연결 도움]
너는 AI 에이전트야. 이 컴퓨터의 파이널 퓨전 받는 앱으로 보내는 맥에 연결하도록 도와줘. 받는 앱에는 보내는 맥의 연결 정보가 이미 들어 있어.
1. 인터넷이 되는지, 보내는 맥에서 파이널 퓨전이 ‘보내기’ 중인지 사용자에게 확인해.
2. 받는 앱에서 ‘연결하기’를 누르게 해. 처음이면 6자리 번호가 나오고, 사용자가 그 번호를 보내는 맥의 파이널 퓨전 「③ 첫 연결」 칸에 입력해 허용해야 해.
3. Windows면 Edge나 Chrome이 필요해. ‘전체 화면’을 누르면 Windows 키·Alt+Tab도 맥으로 가고, Esc를 길게 누르면 나와. 키보드 배열은 설정의 ‘키보드’에서 바꿀 수 있어.
4. 프로그램 설치나 공유기 설정 변경 없이 진행하고, 끝나면 실제 화면이 보이는지 확인해.
5. 쓰다가 불편하면, 원격 화면에서 보내는 맥의 파이널 퓨전을 열고 「④ 바로 고치기」의 「④ 안내 복사」를 눌러 그쪽 AI 도우미에 붙여넣으라고 안내해. 그쪽에서 고치고 받는 앱도 새로 보내 줘.

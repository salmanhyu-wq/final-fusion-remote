이 맥에서 파이널 퓨전 화면 보내기를 준비해줘. 이 버전은 앱이 인터넷 연결 서버에 직접 연결하고, 받는 컴퓨터에서는 별도 연결 앱을 쓰지 않아. 아래에 붙은 중계 설정 폴더의 SETUP.md를 읽어. 이 맥에서 앱 실행 파일에 --relay-id를 붙여 공개 연결 번호를 얻고, 기존 중계 서버가 있다면 상태를 확인해줘. 중계 서버가 아직 없으면 포함된 Cloudflare 무료 플랜 배포용 코드를 검증하고, 내 계정에 배포하기 전에 설치할 내용과 계정을 보여줘. Cloudflare 로그인이나 이용 약관, 결제는 내가 직접 처리할 수 있게 안내해줘. 배포된 HTTPS 주소가 확인되면 앱 실행 파일에 --set-relay <주소>를 붙여 주소를 저장해줘. 앱에서 ‘보내기 시작’을 눌러 화면 녹화와 손쉬운 사용 권한을 내가 허용하도록 안내해줘. 보내기가 켜지면 ‘받는 앱 만들기’에서 Mac용 DMG와 Windows용 EXE를 만들어줘. 첫 연결 때 받는 앱에 나온 6자리 번호는 내가 이 맥의 ‘③ 첫 연결’(또는 ‘새 기기 허용’) 칸에 직접 입력할게.

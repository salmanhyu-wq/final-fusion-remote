# Security

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/salmanhyu-wq/final-fusion-remote/security/advisories/new). Include steps that use dummy accounts and relay settings. Keep real keys, relay addresses, personalized viewer apps and raw diagnostic logs private.

보안 문제는 위 링크에서 비공개로 알려 주세요. 실제 연결 주소, 키, 받는 앱은 첨부하지 마세요.
